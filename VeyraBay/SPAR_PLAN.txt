SPAR-PLAN - so holst du aus deinem Claude-Guthaben am meisten heraus
=====================================================================

EINSTELLUNGEN (in Claude Code "/model" eingeben)
- Modell fuer Routinearbeit: Sonnet 5.5 - kostet nur HALB so viel wie Opus 5.5 und reicht fuer
  Installieren, Kompilierfehler und Python-Fehler. Du bekommst damit etwa doppelt so viel Arbeit.
- Opus 5.5 nur, wenn Sonnet an einem Problem zweimal scheitert oder Bilder/Grafik beurteilt werden sollen.
- Denkstufe (Effort): "high" statt "max". Keinen Fast-Modus (kostet das Doppelte).
- Zuerst dein Pro-Kontingent aufbrauchen - es fuellt sich nach einigen Stunden von selbst wieder auf
  (Anzeige unter Einstellungen -> Nutzung). Das Extra-Guthaben nur nehmen, wenn du nicht warten willst.

SO GEHT'S
- Pro Arbeitspaket eine NEUE Sitzung starten (alte Sitzungen werden mit jeder Nachricht teurer,
  weil Claude den ganzen bisherigen Verlauf mitliest).
- In die Sitzung nur die kurze Zeile des Pakets einfuegen (unten). Beim allerersten Mal stattdessen
  den kompletten Text aus PROMPT_FUER_CLAUDE.txt.
- Wenn Claude "Paket fertig" meldet: Sitzung schliessen, neue starten, naechstes Paket.
